# Мира Тимербаева — страницы

Специалист по нейросетям. Telegram: [@mirashine](https://t.me/mirashine)

Две страницы, собранные вручную: без фреймворков, без библиотек, без сборки.
Каждая — один HTML-файл, который достаточно открыть в браузере.

| Файл | Что это |
|---|---|
| `index.html` | Личная визитка: имя зеркально-малиновым, падающие звёзды на фоне, контакты |
| `landing.html` | Лендинг симулятора «Мышление. Система. Результат» для начинающих фрилансеров |

## Как посмотреть

Скачать файл и открыть двойным кликом — этого достаточно, интернет не нужен.

## Как устроено

Весь CSS и JavaScript лежат внутри самих файлов, иконки нарисованы в SVG,
шрифты берутся системные. Поле галактик на лендинге рисуется на `canvas`
один раз при загрузке, поэтому фон не нагружает страницу.
